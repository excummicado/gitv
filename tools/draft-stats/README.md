# draft-stats

Статистика игроков по выгрузкам API матчей (`{ items: [...], count }`). Зависимостей нет, нужен только Node 18+.

```bash
# сохраните ответы API (все страницы, все турниры) в data/*.json
node draft-stats.mjs data --names names.json --out out
```

- Входы — файлы или папки с `.json`. Матчи с одинаковым `_id` учитываются один раз, так что страницы могут пересекаться.
- `--names` (необязательно) — названия агентов и движков: `{ "agents": { "<id>": "Имя" }, "engines": { ... } }` или массивы `[{ "_id", "name" }]`. Без него вместо названий будут хвосты ID.
- Результат в `out/`: `report.html` (отчёт), `stats.json`, `players.csv`, `games.csv` (каждая игра каждого игрока по порядку), `agents.csv`.

Правила подсчёта (предположения, поправьте в `adjustedTime` и блоке «Итог матча», если на сайте иначе):
- игра (драфт) выиграна тем, у кого меньше `clearTime` + штраф: первые `freeRestarts` рестартов бесплатны, следующие стоят `paidRestarts[k]` секунд;
- матч выигран по меньшей сумме времени за обе игры;
- драфты со статусом не `FINISHED` пропускаются;
- игрок определяется по `users[i]` (порядок `drafts[0].players`), поэтому смена ника не ломает статистику.
