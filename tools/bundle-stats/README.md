# bundle-stats

Оценка связок персонажей в Бездне и Excel-отчёт. Запускать из корня проекта `gitv`.

## Скрипты
- `export.py` - выгрузка из `api/gitv.db` (только чтение) в CSV в `data/`.
- `elo_export.py` - Эло игроков до каждого матча в `data/elo_before.csv`. Только на копии базы, после `alembic upgrade head`; аргументы: путь к копии и выходной CSV.
- `model.py` - модель; читает CSV из `data/`, перезаписывает `data/results/*`. Режим `model.py --score "A,B,C,D" [--mind "A=6,B=2"]` (имена en) оценивает четвёрку по сохранённым коэффициентам без пересчёта; из кода - `score_team(agents, mindscapes=None)`.
- `report.py` - Excel-отчёт из `data/results/`.

## Порядок запуска
```
api/venv/bin/python -I tools/bundle-stats/export.py
api/venv/bin/python -I tools/bundle-stats/elo_export.py <копия_базы.db> tools/bundle-stats/data/elo_before.csv
tools/bundle-stats/.venv/bin/python tools/bundle-stats/model.py
tools/bundle-stats/.venv/bin/python tools/bundle-stats/report.py
```
`export.py` дополнительно пишет `data/agents_meta.csv` (редкость персонажей). При подготовке этой версии полный экспорт не перезапускали: файл `agents_meta.csv` получен вызовом одной функции из `export.py`, остальные CSV в `data/` прежние.

Тесты: `tools/bundle-stats/.venv/bin/python -m pytest tools/bundle-stats/test_report.py -p no:cacheprovider`.
В `.venv` нужны numpy, scipy, openpyxl, pytest.

Команды `export.py` и `model.py` взяты из их шапок. Цепочку целиком (включая `elo_export.py`) при подготовке не запускали.

## Результаты (`data/results/`)
- `pairs.csv` - все 585 пар; новые колонки `p_b_given_a`, `p_a_given_b` (доля игр одного персонажа, где второй в той же половине), `top3_player_share`.
- `current_bundles.csv` - связки действующей системы; новые колонки `agents_ru`, `conditions_ru`.
- `agents.csv` - индивидуальные эффекты персонажей (новая колонка `rarity`).
- `pair_const_grid.csv`, `agent_const.csv` - сетка созвездие x созвездие для пар и уровни созвездий персонажей (версия 3).
- `inseparable.csv` - неразлучные персонажи: совместная оценка «персонаж + пара», цены.
- `teams.csv` - наблюдавшиеся четвёрки (>= 20 игрок-игр и >= 6 игроков) с оценкой модели, остатком и стоимостью.
- `coefs.json`, `coefs_boot.npz` - коэффициенты и бутстрэп для `score_team`; `checks.json` - числа проверок (читает `report.py`).
- `bundles-report.xlsx` - отчёт (листы: «Как читать», «Кандидаты», «Текущие связки», «Все пары», «Созвездия × созвездия», «Созвездия персонажей», «Неразлучные», «Команды»).
- `data/results_v1/` - копия результатов до этой версии, для сравнения (в git не попадает, как и весь `data/`).

## Версия 3 (веса игроков и сетка созвездий)
- Вес игры: min(1, 40 / число игр игрока); взвешенные регрессия, CV и метрики. Добавлен случайный эффект «игрок x персонаж» (от 5 игр).
- Созвездия персонажа: уровни C0..C6 как накопительные индикаторы C>=k со штрафом на каждый шаг (штраф на разности соседних уровней); уровни без данных наследуют соседние.
- Пара: двумерная накопительная сетка по уровням обоих персонажей: база (0,0), поправки по уровню первого и второго (i,0), (0,j), поправки ячейки (i,j). Выбрана накопительная параметризация (а не простой гребень по ячейкам): штраф на шаг даёт интерполяцию по обеим осям. Колонки с одинаковым набором игр склеены (штраф - параллельное соединение), поэтому модель ~8700 колонок.
- Решатель: Холецкий + PCG для бутстрэпа, фолдов и пересчётов без игроков. Штрафы подбираются покоординатно (2 круга); результат кэшируется в `data/results/lam_cache.json` (`model.py --reuse-lam`). Для отложенной проверки штрафы не пересчитывались.
- Заголовочный эффект пары (`pairs.csv`) - среднее синергии по сыгранным ячейкам с весами игроков. `effect_wo_top3` - пересчёт без трёх самых частых игроков пары; `robust` = reliable и тот же знак и |без трёх| >= 0.5|эффект| и >= 15 игроков. Jackknife по игрокам не считали (дорого).
- `pair_const_grid.csv` - 49 ячеек на пару; `agent_const.csv` - уровни персонажей. Условные двухперсонажные связки читаются из сетки: effect = среднее синергии по ячейкам условия с весами `weight_sum`; их отдельные колонки в модели убраны, тройки оставлены.
- Листы отчёта: «Созвездия × созвездия» (только robust-пары и пары из текущих связок), «Созвездия персонажей»; лист «Пары по созвездиям» убран. Файл `pairs_by_const.csv` v2 больше не пишется. Копии прошлых результатов: `data/results_v1/`, `data/results_v2/`.

## Как устроено расширение (версия 2)
- Пары по созвездиям: для пары и каждого из двух её персонажей два индикатора «пара в одной половине И персонаж в корзине C2-C5 / C6» (база - C0-C1), если в корзине >= 30 игрок-игр и >= 8 игроков и в остальной части пары >= 30 игрок-игр. Это отклонения от эффекта пары со своим штрафом (сетка 300 - 100000, подбирается той же кросс-валидацией по турнирам). Индивидуальные корзины созвездий персонажа остались в модели. Если у пары есть условная связка действующей системы с условием на созвездие этого персонажа, поправка не добавляется: её оценивает колонка самой связки (таких 11 сочетаний пара-персонаж, список в логе `model.py`). Другой персонаж пары в оценке корзины стоит на базе.
- Неразлучные: n_a >= 30 и доля игр A, где B в одной половине, >= 0,8 (или в одном драфте >= 0,8 при доле в половине < 0,8). Пары неразлучных сверх обычных порогов получили бы свою колонку; в этих данных такой нет (обе пары в одной половине уже прошли пороги пар).
- Команды: оценка = сумма индивидуальных эффектов (с корзинами созвездий), эффектов пар, поправок по созвездиям и связок, минус то же у средней наблюдавшейся половины (команды), в секундах на игру. Пара без оценки - ноль, их число выводится. «Остаток» - средний остаток игр команды в модели без пар и связок (на секунды за игру).

## Ограничения
Сигнал слабый. На играх после августа 2026 учёт пар не улучшил предсказание времени, поправки по созвездиям не добавили ничего ни в кросс-валидации, ни на отложенных играх, и ни одно отклонение по созвездиям не отличается от нуля после поправки на множественные сравнения. Оценки одной и той же пары на двух случайных половинах игроков совпадают слабо (корреляция 0,24). Две трети эффектов отрицательные, а среди надёжных — 53 из 54: возможно, часть эффекта это «стандартная мета-команда», а не синергия именно этой пары. Реальный разброс шире указанных интервалов. Оценки команд - сумма оценок модели, у команд с малым числом игр и игроков (особенно с высокой долей трёх игроков) они шумные.
